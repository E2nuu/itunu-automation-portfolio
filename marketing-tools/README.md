# 📣 Marketing Tools

Welcome!  
This folder contains practical **marketing, customer-engagement, and workflow-automation tools** built to make outreach operations more organized, measurable, and reliable.

The projects here focus on the work behind a campaign: assigning follow-ups, recording outcomes, maintaining clean records, reporting performance, and giving each role the right workspace.

---

## 🌟 Featured Project

### [**Customer Engagement Workflow Portal**](https://github.com/E2nuu/itunu-automation-portfolio/tree/main/marketing-tools/customer-engagement-workflow-portal)

A full-stack Google Apps Script portfolio application that models a consent-aware customer re-engagement workflow using synthetic data only.

Built for the operational reality behind outreach campaigns: customer queues, call outcomes, follow-up scheduling, verified reactivations, role-based workspaces, and accountable reporting.

#### What it demonstrates

- **Role-aware workspaces** for agents, team leads, executives, and administrators
- **Outbound workflow management** with queue claims, interaction capture, dispositions, and follow-up scheduling
- **Customer-engagement safeguards** including consent status, opt-out handling, validation, and audit trails
- **Executive reporting** with activity trends, lifecycle and outcome charts, cohort views, and a leadership discussion space
- **Workspace administration** for configuration, governance, readiness checks, and synthetic-data maintenance
- **Responsive interface design** for desktop and mobile use
- **Synthetic demo environment** with documented test accounts and no production data

#### Technology

- Google Apps Script
- Google Sheets as a transparent relational data store
- HTML, CSS, and vanilla JavaScript
- Server-side role checks, expiring sessions, script locks, and idempotent writes
- Local service-contract and rules tests

> This is a clean-room portfolio implementation. It contains fictional records only and is not connected to a customer, company, or production system.
