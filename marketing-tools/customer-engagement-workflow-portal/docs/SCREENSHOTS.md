# Reproducible screenshot instructions

1. Deploy the application from a freshly seeded synthetic workbook.
2. Capture the agent dashboard after signing in as `agent@nexaflow.example`.
3. Capture the queue after claiming a work item, showing the customer card and disposition form.
4. Sign in as `lead@nexaflow.example` and capture team analytics with the leaderboard.
5. Sign in as `admin@nexaflow.example` and capture the configuration page.
6. Mask the demo password field if it is visible. Use only the seeded fictional dataset and add no real contacts to the screenshots.

These four views correspond to the principal role-based flows documented in the README.
