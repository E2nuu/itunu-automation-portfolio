# Synthetic dataset

These fictional records are created by `setupNexaFlowSyntheticDatabase()` in a blank Google Sheet. They use reserved `.example` addresses and non-routable illustrative phone numbers. The setup routine creates the relational worksheets, headers, validations, filters, scoring configuration, and a small linked data set for demonstration.

All demo accounts use `ChangeMe!2027` only in the newly-created, synthetic workbook. Change or remove them before sharing a deployment.
