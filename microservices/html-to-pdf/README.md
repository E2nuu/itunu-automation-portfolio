## 🧩 Microservices

A collection of **self-hosted backend microservices** designed to support automation workflows, internal tools, and API-driven systems.

These services are built with an **automation-first mindset**, focusing on reliability, isolation, and simple HTTP-based integration rather than frontend usage.

Each microservice runs independently on private infrastructure and integrates seamlessly with tools like **n8n**, scheduled jobs, or internal applications.

---

## 📦 Included Projects

### HTML to PDF Microservice
A self-hosted HTML → PDF conversion service for automation workflows and backend systems.  
It exposes a secure HTTP endpoint that accepts raw HTML and returns a generated PDF file — making document generation reliable, consistent, and fully automation-ready.
